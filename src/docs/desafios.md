# Desafios do Dia

![Calendário dos Desafios do Dia](screenshots/interface-desafios-1.1.png)

Todos os dias há um exercício **Simples**, para praticar os fundamentos, e um **Avançado**, para explorar problemas maiores. A dificuldade depende do nível escolhido e não do mês do ano.

Escolha uma data disponível no calendário e depois abra um dos dois desafios. Você pode consultar qualquer dia do ano atual, desde 1º de janeiro até hoje. Em 29 de fevereiro, o calendário reapresenta os desafios de 28 de fevereiro.

Leia o objetivo e as regras antes de escrever o algoritmo. Abra um arquivo no editor, implemente sua ideia e execute para comparar a saída com os exemplos. Use as dicas aos poucos. A solução fica fechada inicialmente; consulte-a após tentar resolver o problema e, se quiser, copie o código ou abra-o em outra aba do editor.

## Como entender um exercício

- **Entrada:** o que a pessoa digita para o programa usar.
- **Saída:** o que o programa mostra como resposta.
- **Variável:** um lugar com nome para guardar um valor, como `idade` ou `preco`.
- **Condição:** uma pergunta que o programa responde com sim ou não para escolher um caminho.
- **Repetição:** um trecho que o programa executa várias vezes.
- **Vetor:** uma lista de valores. **Matriz:** uma tabela com linhas e colunas.

Nos exemplos, a seta **→** quer dizer “resulta em”. Alguns exemplos mostram apenas a parte da saída que ajuda a conferir a regra principal; leia também o objetivo e “Como funciona” para saber tudo o que o programa deve fazer. O nível Avançado pode usar conceitos que você ainda não viu. Nesse caso, consulte as palavras úteis do próprio desafio e experimente primeiro um exercício Simples, de qualquer data.

![Material de um desafio simples com objetivo, regras e exemplo](screenshots/interface-desafio-simples-1.1.png)

O nível Avançado tem sua própria página, para que os dois exercícios não fiquem misturados. A solução permanece fechada até você abrir **Ver solução**; depois, pode copiar o código ou abri-lo no editor.
