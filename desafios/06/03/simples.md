# Quadrilha numerada

**Data:** 3 de junho · **Nível:** Simples

## Objetivo

Imprima passos de 1 até 8.

## Como funciona

Imprima os números de 1 a 8, um em cada linha.

### Palavras úteis

- **Laço:** É um trecho do algoritmo que se repete.

## Exemplo de execução

```text
Início: Passo 1
Fim: Passo 8
```

A sequência sempre tem oito passos.

## Dicas para resolução

1. Use um laço para.
2. Comece em 1.
3. Termine em 8.

## Solução

```visualg
algoritmo "Desafio0603S"
var
etapa: inteiro
inicio
para etapa de 1 ate 8 faca
    escreval("Passo ", etapa)
  fimpara
fimalgoritmo
```

O laço percorre exatamente os oito valores desejados.
